# aud_audio_auv3_example

The container app of the example AUv3 of aud_audio_auv3 and its
extension `AudExampleAU` (`com.example.audAudioAuv3Example`, manufacturer `Demo`,
subtype `AExm`): the app loads one to four instances out of process, opens
their Flutter editors and reports the extension's footprint and the first
frames. The README of the repo describes how to build and run it.
